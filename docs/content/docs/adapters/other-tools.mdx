title: "Other tools"
---

The memory is plain markdown, so any agent that can read files and run a shell command can use it.
Install with the `none` adapter:

```bash
npx groundwork-ai init --adapter none
```

You get `AGENTS.md` plus the `.groundwork/` folder, and nothing tool-specific. Most modern agents read
`AGENTS.md` on their own; if yours doesn't, point it there.

Claude Code, OpenCode, Codex, Cursor and Gemini CLI have their own adapters:
[Claude Code](/docs/adapters/claude-code), [OpenCode](/docs/adapters/opencode),
[Codex](/docs/adapters/codex), [Cursor](/docs/adapters/cursor) and [Gemini CLI](/docs/adapters/gemini).
Use `none` for any other tool, or for a tool whose adapter you would rather not install.

## Working without hooks

`AGENTS.md` carries the loop, in instruction form:

1. Start every session with `npx groundwork-ai brief`. It prints the handoff, how far it can be trusted
   against git, the decisions in force, the rules and the map.
2. Save when a step finishes and before stopping:
   `npx groundwork-ai checkpoint --now "…" --next "…"`.

If your tool has no native command, ask your agent:

> Read `.groundwork/commands/gw.md` and follow it.

## What changes without an adapter

| | With an adapter | Plain markdown |
|---|---|---|
| Brief at session start | A hook gives it to the agent | The agent runs `brief` because `AGENTS.md` says to |
| Checkpoint when a turn ends, before a compaction, at session end | A hook runs it, and asks the agent to save if the handoff is behind | Nothing runs it; the agent saves when `AGENTS.md` says to, or you do |
| `/gw` | A native command | Read the command file and follow it |

Honest trade-off: without hooks, saving depends on the agent remembering, which is exactly the weak
point hooks remove. The stamp is still the CLI's: whenever a checkpoint does run, time, commit and
branch come from git, and the next `brief` tells the next session how far behind the handoff is.

With the optional [flow](/docs/flow) on, roles run in one session in turn
([without subagents](/docs/flow/the-build-loop#without-subagents)) and guards are instructions only:
nothing blocks a commit automatically.

## The CLI still helps

```bash
npx groundwork-ai status    # where things stand, from files
npx groundwork-ai doctor    # install health, memory and budgets
npx groundwork-ai brief     # what a new session would be given
npx groundwork-ai upgrade   # refresh Groundwork's own files
```

Nothing in the memory depends on the CLI to be read. It is the deterministic helper: it writes the
facts, and the agent writes the judgment.

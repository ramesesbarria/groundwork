**`.groundwork/JOURNAL.md` is the project's log.** The [handoff](/docs/concepts/handoff) says where
things stand now; the journal says how they got there. `checkpoint` writes it from git, so nobody
has to remember to.

```markdown
## 2026-11-15 08:41 UTC · main @ 5c4bcc2 · claude-code
- First checkpoint: earlier history is in `git log`.
- Now: Login form renders; validation is not wired to the API
- Next: Wire validation in src/login.ts, then add the first test
```

Each entry lists the commits and files since the last one, plus Now and Next at that moment.

## Good to know

- No new commits, no entry. Force one with `checkpoint --note "<text>"`.
- A [worker's](/docs/concepts/parallel-agents) checkpoint doesn't write the journal.
- You can add your own entries. Start each with `## `.
- Over its budget (2,500 tokens by default), [`compact`](/docs/concepts/budgets-and-compaction)
  moves the oldest entries to `.groundwork/archive/`. Nothing is deleted.

---

Your AI tool writes the code. Groundwork gives it a process it can't skip, and keeps the state of
the project in files instead of the chat:

<BuildLoopDiagram />

```bash
cd your-project
npx groundwork-ai init      # Claude Code, OpenCode, or plain markdown
```

Then open your AI tool in the project and type `/gw`.

## New in 0.8.0

The rules are enforced in code now, not only asked for in the prompts:

- **A commit gate.** A card is committed only once it's done and has its evidence; in Claude Code,
  per-card commits also need a message from you. [Evidence and approval →](/docs/concepts/evidence-and-approval#what-approval-refuses)
- **The agent can't switch the checks off.** It can't remove guards, loosen approval or strip
  Groundwork's hooks; you still can. [Configuration →](/docs/reference/configuration#enforce)
- **Build straight through** with `at-end` mode when there's a deadline: every card built and
  committed as a checkpoint, one review, one approval. [Approval modes →](/docs/getting-started/approval-modes#building-straight-through-at-end)
- **Upgrades keep your edits**, and each role gets a rules file upgrades never touch. [CLI →](/docs/reference/cli#upgrade)
- **New commands:** `check`, `mode` and `uninstall`. [CLI →](/docs/reference/cli)
- **Secrets stay out of committed files**, in a git-ignored `.groundwork/private/`. [Project files →](/docs/reference/project-files)

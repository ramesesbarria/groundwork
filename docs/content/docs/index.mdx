---

Your AI tool writes the code. Groundwork gives it a process it can't skip, and keeps the state of
the project in files instead of the chat:

<BuildLoopDiagram />

```bash
cd your-project
npx groundwork-ai init      # Claude Code, OpenCode, or plain markdown
```

Then open your AI tool in the project and type `/gw`.

## New in 0.8.1

- **OpenCode gets the commit gate's human check.** In the default mode, a card commit on OpenCode
  now needs a message from you since the last commit, like Claude Code: the plugin records your
  prompts and ignores subagent ones, so the agent can't approve its own work. Older OpenCode builds
  without the prompt hook keep the card checks alone.
  [OpenCode →](/docs/adapters/opencode#human-only-commands)
- **Tighter harness protection.** The agent can no longer create or edit files in
  `.opencode/plugins/` — plugins run outside the guards — and `git clean` no longer slips past
  protect-harness. [Configuration →](/docs/reference/configuration#enforce)
- From [0.8.0](/docs/concepts/evidence-and-approval): the commit gate, protected setup, fail-safe
  guards, `at-end` mode, and upgrades that keep your edits.

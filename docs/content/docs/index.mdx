**Your AI forgets. Your project doesn't.**

Groundwork is project memory for coding agents. It keeps where the work stands, what comes next and
what you decided in your repo, so a new chat, another tool or a different model picks up where the
last one stopped — and is told what changed before it trusts the notes.

<MemoryLoop />

```bash
cd your-project
npx groundwork-ai init
```

Then open your AI tool and type `/gw`.

## Why you want it

- **No more re-explaining.** Every session opens knowing where you stopped and what is next.
- **Old notes can't pass as current.** Each session is told which commits landed since the last save.
- **Switch freely.** The memory is in your repo, so it works across tools and models.
- **Nothing to sign up for.** Plain markdown files, committed with your code.

## What it remembers

| File | What it holds |
|---|---|
| [`HANDOFF.md`](/docs/concepts/handoff) | Where things stand, and what is next |
| [`MAP.md`](/docs/concepts/map) | Where things are in the codebase |
| [`DECISIONS.md`](/docs/concepts/decisions) | What was decided, and why |
| [`LESSONS.md`](/docs/concepts/lessons-ledger) | Mistakes not to repeat |
| [`JOURNAL.md`](/docs/concepts/journal) | What happened, commit by commit |

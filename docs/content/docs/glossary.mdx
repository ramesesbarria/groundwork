## Project memory

- **Handoff** — where the project stands right now: what is in progress and what is next. `HANDOFF.md`.
- **Checkpoint** — saving the handoff. You write the words; the CLI adds the stamp.
- **Stamp** — the time, commit, branch and writer recorded with each checkpoint.
- **Brief** — what a session reads when it starts: the handoff, how fresh it is, the decisions and the map.
- **Freshness** — how the handoff compares with the repo: `fresh`, `behind`, `diverged`, `stale` or `unstamped`.
- **Map** — where things are in the codebase. `MAP.md`.
- **Decision** — a choice, with the options and the reason. One record each in `decisions/`.
- **Lesson** — a mistake written down so it doesn't happen twice. `LESSONS.md`.
- **Journal** — what happened, checkpoint by checkpoint, taken from git. `JOURNAL.md`.
- **Budget** — a size limit for a memory file, so memory stays small enough to load.
- **Compact** — move old material to `.groundwork/archive/`. Nothing is deleted.
- **Worker** — a parallel agent with its own handoff.
- **Adapter** — the files that connect Groundwork to one tool: Claude Code, OpenCode, Codex, Cursor or Gemini CLI.

## The flow (optional)

- **Flow** — the guided way to build: spec, cards, roles, approvals and guards.
- **Card** — one small piece of work, with a checklist of what "done" means.
- **Phase** — a group of cards that together leave something working.
- **Evidence** — the proof a card is done, such as test output or screenshots.
- **Guard** — a small script that blocks an action outright.
- **Runner** — the main session that hands each card to the roles.
- **Quick path** — one pass for a small, low-risk change: no card, but the checks still run.
- **Baseline** — the state of the checks on an existing project, so only new failures block work.

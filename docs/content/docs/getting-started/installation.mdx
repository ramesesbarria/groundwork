---
title: "Installation"
description: "One command adds project memory to any git repo."
---

You need **Node.js 22 or later** and **git**.

```bash
cd your-project
npx groundwork-ai init
```

It asks which AI tool you use: Claude Code, OpenCode, Codex, Cursor, Gemini CLI, or none (plain
markdown, for any other tool). New or existing project, both work. An existing `AGENTS.md` or
`CLAUDE.md` is added to, never replaced.

## Options

| Command | What it does |
|---|---|
| `init --adapter codex` | Skip the question |
| `init --adapter claude-code,codex` | Set up several tools |
| `init --dry-run` | Show what would change, write nothing |
| `init --flow` | Also add the optional [flow](/docs/flow) |
| `adapter add cursor` | Add another tool later |

## Then

Open your AI tool in the project and type `/gw` (`$gw` in Codex; trust its hooks once with
`/hooks`). The first time, it asks what the project is and fills in the map. After that, every
session starts from the brief.

With plain markdown, `AGENTS.md` tells the agent to run `npx groundwork-ai brief` first. If a
session ever starts without its brief, run that command yourself.

Next: [your first 10 minutes](/docs/getting-started/first-10-minutes).

## What it adds

| Path | What it is |
|---|---|
| `.groundwork/` | The memory files, the `/gw` command and the scripts the hooks run. Commit it |
| `AGENTS.md` | Tells any agent to read the brief first and to save |
| `.claude/`, `.opencode/`, `.codex/` and `.agents/`, `.cursor/`, or `.gemini/` and `GEMINI.md` | Your tool's hooks and `/gw` command |
| `.gitattributes` | Marks images as binary |

Every file is listed in [Project files](/docs/reference/project-files).

## Update or remove

```bash
npx groundwork-ai upgrade      # update Groundwork's files; yours are kept
npx groundwork-ai doctor       # check that everything is healthy
npx groundwork-ai uninstall    # remove only what Groundwork added
```

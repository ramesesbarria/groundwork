---
title: "Upgrading from 1.x"
description: "One command. Everything you made is kept, and the workflow you use stays on."
---

```bash
npx groundwork-ai upgrade --dry-run     # preview
npx groundwork-ai upgrade
```

2.0 puts project memory first and makes the 1.x workflow the optional [flow](/docs/flow). Same
package, same `.groundwork/` folder, same `/gw` commands.

## What happens

| | |
|---|---|
| **Stays on** | The flow: cards, approvals, guards and `check` work as before |
| **Never touched** | `HANDOFF.md`, `SPEC.md`, `LESSONS.md`, `JOURNAL.md`, cards, decisions, evidence, rules, `AGENTS.md`, `CLAUDE.md`, your config values |
| **Added** | `MAP.md`, a generated `DECISIONS.md`, the memory hooks, and four config keys: `flow`, `budgets`, `staleAfterDays`, `nudge` |
| **Updated** | Groundwork's own files. One you edited is kept, with the new version beside it as `<file>.new` |
| **Claude Code** | `SessionStart` is updated in place; `Stop`, `PreCompact` and `SessionEnd` are added. Your own hooks stay |

## Your old handoff

It shows as `unstamped` until the first `checkpoint`, which converts it to the new layout. Nothing
is dropped: Last step becomes Now, Next step becomes Next.

## Your old codebase map

1.x kept it as a section of `SPEC.md`. It stays there. 2.0 adds `.groundwork/MAP.md`; ask your agent
to move the content across.

## Want memory only?

```bash
npx groundwork-ai flow off
```

This removes Groundwork's flow files and keeps your spec, cards, evidence and rules. Only you can
run it; the agent is refused. `AGENTS.md` isn't edited, so update its "How we work" section yourself.

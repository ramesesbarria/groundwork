## Goal
`core/` never depends on one tool; everything tool-specific stays in `cli/src/adapters/`. Planned changes: PLAN.md §10.2.

## Acceptance criteria
- [x] The test passes on today's core, or it finds real leaks and they're fixed
- [x] An install with `--adapter none` shows how to reach every main command from plain markdown

## How to check
Run `npx groundwork-ai init --adapter none` in an empty folder and open AGENTS.md: rule 1 points to `.groundwork/commands/gw.md`, and every command is a file in that folder.

## Goal
Install Groundwork into its own repo and a small sample app, run one card end to end, and fix what breaks.

## Acceptance criteria
- [ ] `init` run on a fresh sample app, then `gw-spec` → `gw-plan` → `gw-next` → `gw-approve` completes one card
- [ ] Resume test (moved from 1.5): stop partway through a card, open a fresh session (ideally a different tool, e.g. OpenCode + DeepSeek), run `gw-resume`, and it continues without redoing finished steps
- [ ] Every problem found is logged in LESSONS.md with its origin
- [ ] A short write-up of the run saved as evidence (it becomes the first draft of the README demo)

## Goal
Generate Claude Code files from the core: commands → `.claude/skills/gw-*/SKILL.md`, roles → `.claude/agents/*.md`.

## Acceptance criteria
- [x] The generator is a pure function (core files in → adapter files out), with snapshot tests
- [x] Generated skills point to the core files instead of copying their content (one source of truth)
- [x] Subagents get only the tools their role needs (e.g. the reviewer cannot edit files)
- [x] Running it twice gives the same output

- Tests after: 132 passed, 27 of them new ([output](../evidence/2.1/test-output.txt))

  - Added beyond the card: a generated `CLAUDE.md` that imports `@AGENTS.md`, since Claude Code doesn't read AGENTS.md by itself. Card 2.2 must not overwrite an existing CLAUDE.md.

## Goal
First-class OpenCode support, so Groundwork works with any model OpenCode runs (e.g. DeepSeek).

## Acceptance criteria
- [x] File formats checked against current OpenCode docs, with the source noted on the card
- [x] A pure generator: commands → OpenCode commands, roles → OpenCode agents (the reviewer can't edit files), guards → an OpenCode plugin where supported
- [x] `init --adapter opencode` works, with snapshot and idempotence tests like the Claude Code adapter
- [x] Anything OpenCode can't do is stated, not faked

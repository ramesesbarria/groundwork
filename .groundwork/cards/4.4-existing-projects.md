## Goal
`gw-setup` works on a repo that already has code (SPEC §11).

## Acceptance criteria
- [ ] Reads the manifest, folder layout, tests, CI and recent git log; drafts AGENTS.md commands and conventions, each marked *found* or *guessed*
- [ ] Drafts a "current state" SPEC.md from the code and asks the human to confirm anything *guessed*
- [ ] Offers to import an existing CLAUDE.md or AGENTS.md into LESSONS as notes with origin "imported"
- [ ] Records the existing stack as accepted decision records, without proposing changes

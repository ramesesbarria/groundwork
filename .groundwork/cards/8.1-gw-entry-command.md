## Goal
`/gw` reads HANDOFF and the cards, says where things stand in plain words, and runs the next step, or asks when the next step is the human's. It replaces `gw-resume`. Planned changes: PLAN.md §8.1.

## Acceptance criteria
- [x] Every state (nothing set up, no spec, spec not confirmed, no cards, card in progress, awaiting approval, otherwise) maps to exactly one action in `gw.md`
- [x] No file refers to `gw-resume` (grep, excluding old cards and evidence)
- [x] The README shows the two-tier command table (main commands, then power commands)
- [x] `init`'s closing message says to type /gw

## How to check
Run `npx groundwork-ai init --adapter claude-code` in an empty folder: the last line says to type /gw. Open Claude Code there, type `/gw`, and it should start setup. Later, `/gw` in a new session should say which card you're on.

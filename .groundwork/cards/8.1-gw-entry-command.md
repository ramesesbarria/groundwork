## Goal
`/gw` reads HANDOFF and the cards, says where things stand in plain words, and runs the next step, or asks when the next step is the human's. It replaces `gw-resume`. Planned changes: PLAN.md §8.1.

## Acceptance criteria
- [ ] Every state (nothing set up, no spec, spec not confirmed, no cards, card in progress, awaiting approval, otherwise) maps to exactly one action in `gw.md`
- [ ] No file refers to `gw-resume` (grep, excluding old cards and evidence)
- [ ] The README shows the two-tier command table (main commands, then power commands)
- [ ] `init`'s closing message says to type /gw

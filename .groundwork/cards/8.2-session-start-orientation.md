## Goal
Every new session, `/clear` or compaction starts with a few lines from HANDOFF saying where things stand and to type /gw. Planned changes: PLAN.md §8.2.

## Acceptance criteria
- [x] Unit test: sample HANDOFF → the expected lines; missing HANDOFF → a fallback line; no `.groundwork/` → no output
- [x] The output stays under about 80 tokens
- [ ] It's checked in a real Claude Code session on Windows (evidence: screenshot or transcript). Not done: it needs a fresh interactive Claude Code session, which only the human can start. The generated hook command was run through Git Bash on Windows instead (see Evidence). The live check is on card 6.1.
- [x] Without an adapter, nothing is lost: the "read HANDOFF first" rule in AGENTS.md still gets a fresh session oriented

## How to check
In a project installed with the Claude Code adapter, open a new Claude Code session and ask "where are we?" before typing anything else. The agent should already know the current card and next step. `/clear` should do the same.

## Goal
The GUARD level of the ladder: small scripts that block an action, wired into Claude Code hooks.

## Acceptance criteria
- [ ] A guard is a Node module in `.groundwork/guards/` exporting `check(action)` → `{ block, reason }`; an action is a shell command or a file write
- [ ] A runner turns a tool's hook input into an action, runs the guards listed in `config.json` (`guards: []`), and blocks with the reason
- [ ] Built-in guard `no-ai-trailers` blocks commit messages that add AI attribution; it's off unless listed
- [ ] The Claude Code adapter adds a `PreToolUse` hook in `.claude/settings.json`; `init` merges into an existing settings file instead of overwriting it
- [ ] Tests cover the guard, the runner (allow and block), and the settings merge

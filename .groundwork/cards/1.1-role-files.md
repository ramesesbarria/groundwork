## Goal
Tool-neutral instructions for planner, tester, implementer and reviewer (SPEC §6).

## Acceptance criteria
- [x] `core/roles/` has one file per role, each with: job, inputs it reads, outputs it writes, and its "must not" list
- [x] Each role file says exactly which files to load (e.g. implementer: its role file + the current card + linked tests only)
- [x] The reviewer checks the diff against the card, SPEC and LESSONS, and cites lesson IDs in its verdict
- [x] Each role file is under 800 tokens

  - Left for card 1.2: who sets `testing` at the start and what happens after approval. The role files point to the workflow for that.

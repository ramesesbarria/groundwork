## Goal
`gw-handoff` and `gw-resume`, so a session can die at any point and a new one (any tool, any model) continues.

## Acceptance criteria
- [x] The HANDOFF.md format has: current card, current role/status, last completed step, next step, failing checks
- [x] `gw-resume` reads only HANDOFF.md + the current card to restart, not the whole repo
- [ ] ~~Manual resume test in a fresh session~~ **moved to card 3.1** with the human's approval (it needs Groundwork installed, from card 2.2)

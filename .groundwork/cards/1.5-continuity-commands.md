## Goal
`gw-handoff` and `gw-resume`, so a session can die at any point and a new one (any tool, any model) continues.

## Acceptance criteria
- [ ] The HANDOFF.md format has: current card, current role/status, last completed step, next step, failing checks
- [ ] `gw-resume` reads only HANDOFF.md + the current card to restart, not the whole repo
- [ ] Manual test: stop partway through a card, start a fresh session, run `gw-resume`, and it continues without redoing finished steps (write-up saved as evidence)

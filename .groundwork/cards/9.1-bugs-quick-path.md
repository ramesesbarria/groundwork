## Goal
A bug with an unclear cause doesn't force a whole card and plan: reproduce it, state the cause, then fix it. Planned changes: PLAN.md §9.1.

## Acceptance criteria
- [x] The bug branch requires a failing test and a stated cause before any fix
- [x] It has a clear exit to a card
- [x] `gw-quick.test.ts` covers the new steps

## How to check
Read "Fixing a bug" in `core/commands/gw-quick.md`: reproduce with a failing test, state the cause in one sentence with evidence, then fix; after two attempts without a cause, stop and suggest a card.
